# DevLearn — 05 Marketing Website, Settings & Production Polish

## Purpose

Define the public marketing website, user preference configuration, and final production polish.

---

## 1. Marketing Website (`apps/web/app/(marketing)`)

- Hero section explaining the problem and product value proposition.
- Interactive product demonstration previewing timer, contribution calendar, and analytics.
- Feature highlights (Private-by-default, dynamic subjects, developer-first monochrome aesthetic).
- FAQ and Call-To-Action (Register / Log In).

---

## 2. User Settings (`apps/web/app/(portal)/settings`)

- Change daily learning goal (minutes).
- Configure timezone.
- Password change and session review.
- Export learning data (JSON/CSV).
